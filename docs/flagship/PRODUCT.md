# AvtoNetGaraža — flagship redesign

A private shortlist for your next car.

## Delivered

Full-tab garage; compact launcher; highlighted comparison differences and asking-price gaps; personal buying notes and checklist; validated merge-only backup recovery.

## Compatibility

Existing identity, permissions and legacy storage keys are preserved. New preferences use separate keys or additive vehicle fields. No tracking backend or telemetry was added.

## Candidate

Version 1.2.0. Rebuild with `npm ci` and `npm run package` in `extension`. Run `npm run test:extension` for legacy and new browser journeys. Fixtures use disposable Chromium profiles. They do not represent real participant research.

## Limits

Live avto.net access remains blocked. Photos depend on the listing host; no live monitoring claim. Service reminders are visible in the garage, not scheduled push alerts.
