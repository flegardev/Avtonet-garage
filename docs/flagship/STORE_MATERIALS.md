# Store material draft — AvtoNetGaraža

## Short positioning

A private shortlist for your next car.

## Description

Full-tab garage; compact launcher; highlighted comparison differences and asking-price gaps; personal buying notes and checklist; validated merge-only backup recovery.

Your data stays in this Chrome profile. No account or analytics service is required. Existing settings and records are retained on upgrade. Back up important data before changing browsers or removing an extension.

Live avto.net access remains blocked. Photos depend on the listing host; no live monitoring claim. Service reminders are visible in the garage, not scheduled push alerts.

## Update notes

Version 1.2.0 introduces the redesigned interface and workflows described above. Existing product identity and permission scope are unchanged.

## Support

Report a reproducible problem at https://github.com/flegardev/Avtonet-garage/issues. Include Chrome version, steps and redacted screenshots. Never attach browsing-history exports or private vehicle notes to a public issue.

## Screenshots

Use actual `docs/flagship/screenshots/` captures. Test data must be labeled illustrative; screenshots are not evidence of real personal activity or current vehicle availability. Existing icons remain in the package to preserve recognition.
